# e_lecture
projeto sobre leitura de livros em CRUD

## Como iniciar o projeto

1. Baixe o MariaDB
2. Coloque o banco.db no MariaDB
3. Baixe o xampp (já vem com o php nele)
4. ligue o modulo apache
5. ligue o modeulo MySQL
Atenção: defina a porta como a mesma usada no Maria DB
6. Coloque o projeto em uma nova pasta em C:\xampp\htdocs\sua_pasta
7. no navegador vá em http://localhost/sua_pasta/index.php
