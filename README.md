# e_lecture
projeto sobre leitura de livros em CRUD

## Como iniciar o projeto

1. Baixe o MariaDB
2. Coloque o banco.db no MariaDB via comando
3. Baixe o xampp (já vem com o php nele)
4. ligue o modulo apache
5. ligue o modulo MySQL
Atenção: defina a porta como sendo distinta da usada no MariaDB para não dar conflito, edite o arquivo de configuração usado no MYSQL em "port" alterando seu valor
6. Coloque o projeto em uma nova pasta em C:\xampp\htdocs\sua_pasta
7. no navegador vá em http://localhost/sua_pasta/index.html
